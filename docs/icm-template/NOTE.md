# Sursa metodei, nu harta produsului

Aceste fișiere sunt template-ul gratuit [ktnCodes/icm-template](https://github.com/ktnCodes/icm-template) (MIT), metoda din clip: folderele sunt harta, agentul încarcă un singur context. Aceeași copie stă și în RelayHub.

`IDENTITY.md` de aici descrie template-ul, nu Money Scanner. Harta produsului este `AGENTS.md` din rădăcina repo-ului.
